# Argolink facts and review boundary

The stable public boundary is `https://api.argolink.io`. Model discovery is available from `GET /v1/models`; authenticated generation routes require `Authorization: Bearer $ARGOLINK_API_KEY`.

Model IDs, limits, prices, accepted media fields, status values, and response shapes are live facts. Recheck the linked Argolink page before changing examples or claiming a capability. Keep one copy of each fact in the model-specific guide so the README remains an entry point.
